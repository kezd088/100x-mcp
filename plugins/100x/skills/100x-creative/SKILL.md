---
name: 100x-creative
description: 用 100x MCP 在 Codex 中生成或编辑图片、生成视频。适用于用户指定 100x，或要使用 100x 的 GPT 2.5、Grok、Google Omni、Nano Banana、MiniMax H3 型号时。
---

使用可用的 `100x_*` MCP 工具完成创作。工具名可能带安装命名空间前缀，按后缀识别。

主要使用场景是 Codex 桌面端对话，无需另开 CLI 会话。插件安装后在新任务中加载；连接未配置时请用户在自己的 PowerShell 运行安装器 `-Connect`，不要索取令牌到聊天，也不要索取模型厂商密钥。`100x_connection_status` 只检查配置，连通性仍需型号或余额工具验证。

1. 每个会话首次使用时调用 `100x_list_models`。从返回的可用型号和 variants 选择匹配的模式、分辨率、比例和时长，不自行猜测规格。
2. 有参考素材时先上传，取得 `100x_asset_*` 编号。`text` 不含参考素材；`reference` 为参考创作；`first_frame` 为首帧；`first_last_frame` 为首尾帧。每种模式以模型目录为准。
3. 调用 `100x_quote`，返回当前账户的准确积分报价。用户已授权生成且给出预算时，在预算内直接提交；只要求报价时停在报价。缺少预算且费用未获授权时简短说明本次报价。
4. 调用 `100x_generate_image` 或 `100x_generate_video`，传入报价编号和 `max_credits`。为每个创作意图生成一次 UUID 作为 `idempotency_key`。重试同一意图时复用原报价和原编号；不要为网络重试新建付费任务。一次调用只生成一张图片或一段视频。
5. 取得任务号就告诉用户已提交。按 `poll_after_ms` 查询 `100x_get_task`；状态未变时避免重复刷消息。成功后使用包内 `media.mjs download` 把 `outputs` 中的 100x 链接保存到当前任务的 `outputs/100x/` 下，文件名使用任务编号且不能覆盖现有文件。遵守宿主媒体政策；不允许为绕过展示限制而下载时，使用原生预览或返回 100x 链接。保存允许时，图片用 `![100x 图片](/实际绝对路径.png)` 显示；视频用宿主支持的本地媒体预览，否则提供可点击的绝对路径文件。不要把提交耗时说成成片耗时。

本地文件上传：读取 [素材操作说明](references/files.md)，使用包内脚本。不要把完整 base64 塞进对话。

错误处理：`100X_BUDGET_EXCEEDED` 不提交；`100X_QUOTE_CHANGED` 重新报价；`submission_unknown` 使用原报价和原请求编号重试；失败状态停止轮询，保留任务号。只为明确可重试的连接失败重试一次；仍失败就报告任务号和状态。正式失败后的再生成是新付费意图，沿用用户预算边界。

工具不可用时明确报告未连接 100x，不改用别的生成服务。回复保留 100x 型号、任务号、积分和结果链接，不猜测内部执行细节。
